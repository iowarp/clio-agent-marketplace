This release updates shared background-work guidance and scientific agents'
diagram and repository-inspection capabilities.

### Inspect work and choose suitable diagrams
Agents retain accepted assignments and use the shared task controls to observe,
wait, pause or cancel work. Diagram selection follows the active catalog's
supported families and viewer capabilities. Read-only inspection helps agents
understand an unfamiliar repository before explaining it.

The changed packs are Base Agent 0.2.9, APPL-CORE 0.2.6, Factorio Flat 0.4.4 and
EarthScope 0.4.4. They require CLIO 0.9.5b8 or later. (#95, #106)
