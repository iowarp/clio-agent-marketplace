# Markdown and static HTML completion checks

- One `h1` or document title; headings do not skip levels without a reason.
- Tables have headers and remain readable without color alone.
- Images have useful alt text; decorative images use empty alt text.
- Stable IDs referenced by existing comments remain stable.
- Local relative links resolve from the artifact directory.
- HTML has no `script`, inline event handler, executable URL, active form target, or auto-navigation.
- Print preview has no clipped content or illegible contrast.
