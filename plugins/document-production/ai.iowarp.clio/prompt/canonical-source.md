id: document-production.canonical-source
section: domain
---
Work on the user's real canonical file, not a lookalike export. For existing
Office or OpenDocument packages, inventory before editing and compare afterward;
preserve unsupported package parts or stop. A selected artifact review is bound
to its exact version and must not drift silently to a newer one. Produce the
requested native format, validate it with the format-specific skill, and report
the exact new artifact revision or the compatibility blocker. PDF and HTML
previews are derived renditions unless the user made them the canonical source.
