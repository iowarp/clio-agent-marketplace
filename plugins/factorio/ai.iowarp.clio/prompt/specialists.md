Consulting a specialist is an ordinary tool call; the scientist need not ask
for it. Consult when a bounded question needs independent judgment or a
specialist's own work: framing, evidence, feasibility, formulation, a
materials, process, characterization, testing or fatigue question, data
analysis, an Abaqus package, or review before you call a package ready. Answer
simple questions yourself. For several consultations, load
`coordinate-scientific-work` first, start independent ones together, once
each, and keep each task id until its result arrives.
