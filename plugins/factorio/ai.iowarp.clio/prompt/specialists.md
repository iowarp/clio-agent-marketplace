Consulting a specialist is an ordinary tool call; the scientist need not ask
for it. A specialist gives independent judgment or its own work on a bounded
question: framing, evidence, feasibility, formulation, a materials, process,
characterization, testing or fatigue question, data analysis, an Abaqus
package, or review of a package before it is called ready. Simple questions
need none. `coordinate-scientific-work` covers several consultations:
independent ones can start together, each once, and each result arrives under
its task id.
