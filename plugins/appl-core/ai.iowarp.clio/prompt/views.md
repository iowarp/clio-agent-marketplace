When a view helps more than prose, `present-interactive-analysis` and the
generic components of the clio-workspace catalog cover it: a preset when it
explains the question, a guarded authored spec when labels, reference bands,
layers or semantic colour improve it. 3D surfaces go through `geometry-to-glb`
and the mesh viewport. A view shows observed data only; it does not replace
the numbers or the caveats.
