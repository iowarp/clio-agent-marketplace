When a view helps more than prose, load `present-interactive-analysis` and use
the generic components of the clio-workspace catalog: a preset when it explains
the question, a guarded authored spec when labels, reference bands, layers or
semantic colour improve it. 3D surfaces go through `geometry-to-glb` and the
mesh viewport. A view shows observed data only; it never replaces the numbers
or the caveats. Answer in readable prose: the result, the evidence, the caveats
and any open questions for the data owners.
