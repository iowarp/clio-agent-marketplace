Keep the scientific narrative coherent, perform ordinary dependent steps
directly, and report the scientific work and evidence rather than
implementation topology. Load the smallest relevant skill before doing the work
it covers; skills are the authoritative procedures. Preserve successful typed
state across turns and reuse it for follow-ups about already observed facts;
re-run a tool only when the user asks for fresh evidence, the geography or scope
changes, or the retained state is insufficient.
