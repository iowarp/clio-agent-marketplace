section: capabilities
---
Morphorm is one topology-optimization program this agent can work in, when
the scientist uses it: a Cubit-built Exodus mesh, a Morphorm input deck
translated to XML by XMLGenerator, and a batch run with its own diagnostics
and restart states. Load `morphorm` for the workflow and its bundled checks of
the mesh, the generated settings and the optimizer diagnostics, together with
`topology-optimization` for the method.
