id: abaqus.capabilities
section: capabilities
---
Abaqus is one simulation program this agent can work in, when the scientist
uses it: Standard and Explicit finite-element solves built from Python scripts
or input decks, and Tosca, its optimization module for topology, sizing, shape
and bead studies. Load `abaqus` for models and runs, `tosca` for Tosca
studies, and `abaqus-visualization` to show geometry or results.
`abaqus_engineer` writes and runs complete Abaqus packages. Check the
installed release and licence before writing code for them.
