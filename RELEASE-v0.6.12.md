This release updates the standard CLIO agents' shared presentation, task and
dataset guidance while retaining each specialist's declared capabilities.

### Evidence and visual review
Agents can choose diagrams, HTML or SVG when they help explain the material.
Layout follows the content, and visual review captures the actual view, inspects
the image and repeats after repairs. APPL-CORE uses natural citations and adapts
its analysis to unfamiliar read-only exports.

### Search and managed work
The CLIO Search blueprint provides bounded read-only discovery. Shared guidance
covers managed execution/document tools, accepted background tasks and honest
onboarding checks before reporting readiness.

The changed standard packs are Base Agent 0.2.8, APPL-CORE 0.2.5, Factorio Flat
0.4.3 and EarthScope 0.4.3. See CHANGELOG.md and integration PR 91 for validation
and the preserved feature history.
